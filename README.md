# RTAI-Toolbox
运行在小天才RTOS手表上面的DeepSeek客户端
支持机型：
Z 系列
Z6S Z6 Pro（含少年版） Z7 Pro Z9A
D 系列
D1S D2 D2A
Q 系列
Q1 Q1A Q1C Q1R Q2A Q3
其他型号：
N5、Q3A
以上型号都可以安装
需要最低的内存和存储大小：128MB + 128MB
———————————————————————————————————
如何使用？
将压缩包下载下来，然后使用7-zip等压缩软件解压至电脑
用4点数据线连接电脑，找到空间最大的盘符，依次打开：
quickapp\install\
找到.com.neteasemusic文件夹，并替换成刚才解压完成的DeepSeek客户端文件夹
拔下4点数据线，重启手表即可看到应用（应用名称为网易云音乐，没有修改应用名称）
